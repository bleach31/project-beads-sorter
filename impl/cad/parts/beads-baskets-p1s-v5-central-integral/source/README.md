# 配置の再生成

これは同梱済みのSTLを配置するプログラムです。部品の形状を生成または変更しません。

Pythonと `requirements.txt` のライブラリを用意し、`python pack.py` を実行すると、`layout.json` に従って印刷用3MF、配置画像、配置検査JSONを生成します。画像の日本語フォントにはWindowsのMeiryoを使用しています。別の環境では `render` 内のフォントパスを変更してください。

部品の三角形を水平面へ投影した点群の凸包を使い、周囲5 mmがP1Sの256 mm角の範囲内に収まること、左手前18 × 28 mmの除外域を避けること、全ての部品間に10 mm以上の距離があることを検査します。実際のサポートを生成するスライサーではありません。
