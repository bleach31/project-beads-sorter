# 同梱の延長スロープについて

このパッケージの `smooth_u_chute_plus20.stl` は、`beads-chute-plus20-v1` の納品STLと同じファイルです。この配置変更で流路や差込部は作り直していません。

| 項目 | 値 |
|---|---:|
| 回転中心から出口までの水平距離 | 126 mm（従来106 mm） |
| 元の形状を保つ根元の範囲 | 中心から20 mmまで |
| 勾配が滑らかに変わる範囲 | 中心から20〜40 mm |
| 根元の傾斜 | 約22.68° |
| 末端の傾斜 | 約18.04° |
| 主流路内幅と深さ | 12 mm、6 mm |
| 流路断面 | 内半径6 mmの半円 |
| 出口内底と外底の机面からの高さ | 38.0 mm、36.2 mm |
| トレー上端の机面からの高さ | 30 mm |
| 単品の印刷向き外寸 | 約142.2 × 15.6 × 16.2 mm |

入口内幅は元と同じ10.4 mmから12 mmへの移行部を残しています。段差、上り坂、絞りは追加していません。底中央の縦方向厚さは1.8 mmですが、外側斜面に直角な最短肉厚は約1.33 mmです。

納品時の寸法検査では、根元20 mmと軸穴はv5に一致し、全長が下り勾配であることを確認しました。元の評価と同じ公称条件および半径方向の傾き±1.2°、軸の下がり0.3 mmを含む1626姿勢では、参照本体とトレーへの干渉はありません。傾く方向を全方位へ広げたトレーへの隙間の下限は約3.27 mmです。

全方位の傾き確認では、可動範囲の端の23°で、元からある入口外縁と上部部品に微小接触が残りました。最大交差体積は約0.00231 mm³で、v5にも同じ接触があります。「新しい干渉がない」ことと「全条件で干渉がゼロ」であることは異なります。実物では印刷誤差や軸の傾きがあるため、入口側の隙間も手で旋回させて確認してください。

稼働時はトレーの蓋と中央保管ケースを外します。参照モデルの可動範囲は基準方向から23〜293°の270°です。全周回転する形状ではありません。

印刷時は長い外底が約6.9 mm浮くため通常サポートが必要です。サポート除去後は入口、出口、軸穴のバリを整え、少数のビーズで通過を確認します。はめ合い、滑りやすさ、たわみ、誤投入率、印刷時間は実機未確認です。初期位置のキャリブレーション手順と既存の制御は変更していません。
